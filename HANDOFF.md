## Исходник Pencil

Базовый редактируемый документ сохранён локально. Он содержит 20 досок, 26 переиспользуемых компонентов и 17 переменных. В GitHub файл `.pen` не публикуется.

Этот статус относится к сохранённой базовой библиотеке и не подтверждает сохранение в том же файле всех последующих рекламных досок. PNG и PDF не заменяют редактируемый исходник.

## Работа с комплектом

Новые заголовки оформляются без точек. Холодный фиолетовый `#8D7BFF` остаётся рабочим значением. Реальные фото предпочтительны; исторические макеты выделяются как архив.

Рабочий стол использует настоящие ярлыки Windows `.lnk`. Редактор меняет фоновые области, без установки приложений и впечатывания иконок в обои.

Карта и меню — демонстрационные сценарии с явно указанными границами актуальности. Публикация не подключает рабочее бронирование, API тарифов или наличие товаров.
